# 🌙 ねんねログ — 子供の睡眠記録アプリ

子供が **ベットに入った時間 / 寝た時間 / 起きた時間** を記録して、
睡眠時間や寝つきまでの時間を自動で計算・可視化するWebアプリです。

ビルド不要・サーバー不要の静的サイト（HTML / CSS / JavaScript）で、
データは端末のブラウザ内（localStorage）にのみ保存されます。

## 使い方

ローカルサーバーで開いてください（`file://` で直接開くとブラウザによっては保存が効きません）。

```bash
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

GitHub Pages などの静的ホスティングにそのまま置いても動きます。

## 機能

| 機能 | 説明 |
| --- | --- |
| 記録 | 日付・🛏 ベットに入った時間・😴 寝た時間・☀️ 起きた時間・メモを登録 |
| 「今」ボタン | 現在時刻をワンタップで入力 |
| 日跨ぎの自動判定 | 前の時刻より小さい時刻は翌日として扱う（例 23:40 → 翌 00:20 → 翌 07:15） |
| 自動計算 | 寝つきまでの時間 / 睡眠時間 / ベット滞在時間 |
| サマリー | 7日・30日・全期間での平均睡眠時間、平均寝つき、平均就寝時刻、平均起床時刻 |
| タイムライン | 1日1行の帯グラフ。淡い帯＝ベット〜入眠、濃い帯＝睡眠 |
| 一覧 | 新しい順に表示、編集・削除が可能 |
| 兄弟姉妹対応 | お子さんを複数登録して切り替え |
| 書き出し / 復元 | CSV出力（Excel対応のBOM付き）、JSONバックアップと復元 |

## 記録のルール

- 日付は **「ベットに入った日」** を基準にします。夜20時に寝て翌朝6時に起きた場合、日付は前日の夜の日付です。
- 午前0時〜12時に開いたときは、既定の日付が「前日」になります（朝に前夜の記録をつけるため）。
- 時刻は3つすべて必須ではなく、1つ以上入力すれば保存できます。入力された分だけ計算されます。
- 昼寝も同じフォームで記録できます（例 13:00 → 13:20 → 15:00）。

## ファイル構成

```
index.html   画面の構造
styles.css   スタイル（ライト / ダークモード対応、モバイル優先）
app.js       記録の保存・時刻計算・集計・描画（依存ライブラリなし）
```

## データについて

- 保存先はブラウザの localStorage（キー: `nenne-log.v1`）です。サーバーには送信されません。
- ブラウザのデータを消すと記録も消えます。**「バックアップ」でJSONを書き出して保管**してください。
- 別の端末やブラウザに移すときは、書き出したJSONを「復元」から読み込みます。
